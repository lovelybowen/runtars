RunTars v0.5.0 incorporates [Rakazo v0.16.0](https://github.com/elie222/rakazo/releases/tag/v0.16.0).

## Chat, models and routines

- Choose image and video models on a connection that supports media generation. Set a default thinking level for chats, bots and roles that use the connection.
- Bots can save time-limited rules and correct facts in their private memory. A recurring routine waits for its active run to finish before starting another.

## Security

- The API checks the origin of signed-in browser requests. Production servers exclude local Expo development origins.
- A bot running unattended needs fresh owner approval for each bot-management change. Saving an MCP server and its bot access list now succeeds or fails together.
- The Claude Code setup-token flow keeps the operator’s account email out of the model context.

## Downloads

- **Windows x64** — Install the signed `RunTars-Setup-0.5.0.exe`. SmartScreen may prompt on first launch.
- **Linux x64** — Make `RunTars-0.5.0-x64.AppImage` executable and open it. Check the desktop downloads against the attached `SHA256SUMS`.
- **Android 1.0.20** — The message box stays visible above the keyboard, and chats with Mermaid diagrams open and show the full diagram. Manage saved MCP servers from mobile settings. [Rolling APK](https://github.com/lovelybowen/runtars/releases/download/android/runtars.apk)

## Self-host upgrade

Pin the app, computer and updater images under `ghcr.io/lovelybowen/runtars` to `v0.5.0`. Check that your web origin is trusted. Set `AUTH_RATE_LIMIT_ENABLED=true` if you run the API without `NODE_ENV=production` and want sign-in rate limits. When using the new standalone Compose install, back up its `secrets` volume alongside the database. [Full upstream changes and upgrade notes](https://github.com/lovelybowen/runtars/blob/v0.5.0/CHANGELOG.md#0160---2026-11-24)
