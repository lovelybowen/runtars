RunTars v0.1.0 is the first release of the RunTars web application and Docker Compose distribution. It is based on Rakazo v0.12.0 and includes the upstream fixes listed in the [changelog](https://github.com/lovelybowen/runtars/blob/v0.1.0/CHANGELOG.md).

### Self-hosting

Set `RAKAZO_IMAGE_TAG=v0.1.0` and follow the [Compose installation guide](https://github.com/lovelybowen/runtars/blob/v0.1.0/docs/self-host.md#published-images-no-checkout). The installer uses the matching release configuration. All three images support Linux on amd64 and arm64.

| Image                                         | Purpose                         |
| --------------------------------------------- | ------------------------------- |
| `ghcr.io/lovelybowen/runtars/app:v0.1.0`      | Web, API, worker and supervisor |
| `ghcr.io/lovelybowen/runtars/computer:v0.1.0` | Docker bot computers            |
| `ghcr.io/lovelybowen/runtars/updater:v0.1.0`  | Optional updater                |

Existing operators should review the [upgrade instructions](https://github.com/lovelybowen/runtars/blob/v0.1.0/docs/self-host-upgrading.md) before changing their deployment. Desktop and mobile downloads continue to use upstream builds.
