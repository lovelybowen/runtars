RunTars v0.2.0 incorporates the Rakazo v0.13.0 changes and keeps the RunTars update channel, public documentation, and signed Windows and Android downloads.

### Security

- Approval settings cover routines and connected chat apps. Auto Review considers recent owner instructions and can ask before sending information to an unfamiliar site. Outside content can trigger additional checks when a bot saves a skill or creates a trigger. Unattended approvals expire after 30 minutes. Review bots configured with **Never ask** before upgrading. See [approvals](https://github.com/lovelybowen/runtars/blob/v0.2.0/docs/approvals.md).
- Remote secret stores clean up unused credentials after interrupted writes, replaced sign-ins, and deletion of accounts or spaces. Billing expires pending checkout sessions when an organization is deleted.
- Plugin detail pages offer a source link only for HTTPS addresses without embedded credentials. Screenshot jobs receive narrower credentials, messaging address errors omit the address, and the inbound email authentication dependency has been updated.

### Chat, routines and integrations

- Edit plain-text email and Slack drafts before approving them. Start routines from webhooks, Git events, chat messages or email, and choose whether a routine posts into an existing chat.
- Invite guests to individual spaces. An optional model picker is available in the web, desktop and mobile composers.
- Configured meeting bots can join supported calls, return speaker-labeled transcripts and attend scheduled calendar events. See [meeting setup](https://github.com/lovelybowen/runtars/blob/v0.2.0/docs/self-host-meetings.md).
- The built-in RunTars help skill uses the public RunTars documentation. Desktop sign-in handles delayed and duplicate callbacks.

### Downloads

Download `RunTars-Setup-0.2.0.exe` for Windows x64 or `RunTars-0.2.0.apk` for Android. Verify the files against the attached `SHA256SUMS`. Install over the matching previous client to upgrade. Windows uses the project's self-signed certificate, so SmartScreen may warn. The APK uses manual updates and does not include push notifications or background incoming-call alerts.

### Self-host upgrade notes

- Back up the database and application files together. Pin both `RAKAZO_IMAGE_TAG` and `RAKAZO_COMPUTER_IMAGE_TAG` to `v0.2.0`. Fresh published-image installations default to stable images. Scheduled updates are opt-in. See [upgrading](https://github.com/lovelybowen/runtars/blob/v0.2.0/docs/self-host-upgrading.md).
- Allow the previous API and workers to drain before enabling `MODEL_CREDIT_OFFERINGS` or applying deferred drops. Operators using Executor or Outlook shared mailbox tools should reconnect those integrations. Self-hosted Supermemory needs v0.0.9 or later for the new namespace API.
- New credential writes use scrypt with a random salt. Legacy ciphertext remains readable and retains its offline guessing risk when the original deployment key was weak. [Legacy reader follow-up](https://github.com/lovelybowen/runtars/issues/17).
