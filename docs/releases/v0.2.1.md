## Desktop and self-hosting

Windows x64 uses the signed NSIS installer, `RunTars-Setup-0.2.1.exe`. Windows SmartScreen may prompt when you open the installer. On Linux x64, make `RunTars-0.2.1-x64.AppImage` executable and open it. Upgrade either desktop client manually. Download both files alongside `SHA256SUMS` and run `sha256sum -c SHA256SUMS` to check them.

For self-hosting, pin the app, computer and updater images under `ghcr.io/lovelybowen/runtars` to the same `v0.2.1` tag.

## Android

Android has a separate [APK download](https://github.com/lovelybowen/runtars/releases/download/android/runtars.apk). The new signing key requires users of the previous RunTars APK to uninstall it before installing this version. Keep any local data you need before removing your old installation. The APK uses the production update channel. Push notifications require Firebase configuration.
