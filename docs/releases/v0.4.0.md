RunTars v0.4.0 incorporates [Rakazo v0.15.0](https://github.com/elie222/rakazo/releases/tag/v0.15.0).

## Chat and routines

- Attach Word documents and PowerPoint presentations to chats, receive them from bots, and browse chat images in a lightbox.
- Routine owners can enable **Use my computer** for a paired desktop. Runs use the same approvals as chat. A routine pauses after five consecutive failures that need its owner's attention.
- Self-hosters can connect GitHub, Linear and Notion directly and search the public MCP directory from Integrations.

## Security

Changing an MCP server's address clears credentials associated with the previous endpoint. Navigation links reject encoded and mixed-case application routes, vault login fields discourage password-manager autofill, and the web server validates its build ID before accessing the asset archive.

## Downloads

- **Windows x64** — Install the signed `RunTars-Setup-0.4.0.exe`. SmartScreen may prompt on first launch.
- **Linux x64** — Make `RunTars-0.4.0-x64.AppImage` executable and open it. Verify the desktop downloads with the attached `SHA256SUMS`.
- **Android** — The [rolling APK](https://github.com/lovelybowen/runtars/releases/download/android/runtars.apk) uses its own version sequence. Android 1.0.19 fixes dictation with a transcription provider and horizontal scrolling in wide code blocks and tables. Swipe through images and videos in Artifacts and save them to your photo library.

## Self-host upgrade

Pin the app, computer and updater images under `ghcr.io/lovelybowen/runtars` to `v0.4.0`. Webhook ingress is opt-in through `INGRESS_PROVIDER`. The bot-to-bot message limit is now fixed at 100 and `BOT_MESSAGE_MAX_HOPS` has been removed. See the [upstream changes and upgrade notes](https://github.com/lovelybowen/runtars/blob/v0.4.0/CHANGELOG.md#0150---2026-11-23).
