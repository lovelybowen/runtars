RunTars v0.1.1 adds Windows and Android downloads alongside the web application and Compose server.

### Client downloads

- **Windows x64** — Download `RunTars-Setup-0.1.1.exe`. The installer and app have timestamped signatures from the project's self-signed certificate. Windows may show a SmartScreen warning and managed devices may block installation. The signing certificate's SHA-256 fingerprint is `D2DD9F4B9B6193A04CD4DF900C04E1A57E1EFFE48807CB098ABE308610382892`. Install newer releases manually.
- **Android** — Download `RunTars-0.1.1.apk`. This universal APK upgrades the previous RunTars Android build in place using the same package and release key. Push notifications and background incoming-call alerts are unavailable in this distribution.

Both downloads use the RunTars hosted application by default. Verify the downloads against the attached `SHA256SUMS`.

### Web and self-hosting

Web sign-in and sign-up use the RunTars icon. The account menu opens the product documentation and setup instructions use the RunTars name.

Compose operators can pin `RAKAZO_IMAGE_TAG=v0.1.1`. See the [upgrade instructions](https://github.com/lovelybowen/runtars/blob/v0.1.1/docs/self-host-upgrading.md).

The locked picomatch versions still carry the [known denial-of-service advisory](https://github.com/advisories/GHSA-fc5q-39xc-vjpf). The reviewed page-compilation and snapshot-selection paths do not pass user-supplied glob patterns to the matcher.
